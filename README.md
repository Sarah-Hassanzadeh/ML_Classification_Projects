# ML Classification Projects

A collection of three machine learning projects where several classic algorithms are implemented and compared on classification tasks.

## Projects

| # | Notebook | Task |
|---|----------|------|
| 1 | `01_breast_cancer_detection.ipynb` | Classify breast tumors as malignant or benign |
| 2 | `02_digit_recognition.ipynb` | Recognize handwritten digits (0-9) from images |
| 3 | `03_digits_dimensionality_reduction.ipynb` | Improve digit recognition using dimensionality reduction |

## Algorithms

**Project 1 - Breast Cancer Detection**
Naive Bayes, KNN, Decision Tree, Random Forest, SVM, Logistic Regression, Artificial Neural Network (ANN)

**Project 2 - Digit Recognition**
KNN, Random Forest, SVM, ANN

**Project 3 - Digit Recognition + Dimensionality Reduction**
KNN, Random Forest, SVM, ANN (trained on the reduced features)⁸

## Workflow

1. Load and explore the dataset
2. Preprocess the data (scaling, train/test split)
3. Train each model
4. Evaluate with accuracy (and confusion matrix where useful)
5. Compare the models

## Tech Stack

Python, NumPy, Pandas, Scikit-learn, Matplotlib, Jupyter Notebook
